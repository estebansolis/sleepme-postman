Sleepme CLI commands

Run from the repository root. Set SleepMeAPI_Token and device_id in a private Postman environment and replace /path/to/private.environment.json below with its path.
Edit temperature payloads in the saved requests to choose your temperature. Set time_zone, days_back, and optional start_date in the environment as needed.
PATCH commands change the device only when allowed_control_request matches the exact request name. Each PATCH command below opts in to that one recipe for this run; other controls remain skipped. A token and device_id are required.
Rate limit: 10 requests/account/discrete minute; handle 429 with exponential backoff.

References: https://docs.developer.sleep.me/api/ and https://docs.developer.sleep.me/docs/apiexamples/

List Devices
postman collection run postman/files/sleepme-public-developer-api.postman_collection.json -i "List Devices" -e /path/to/private.environment.json --no-report-events

Get Device Status

Update Device Status
